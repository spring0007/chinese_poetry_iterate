《御定全唐詩》
===============

《全唐诗》，是清康熙四十四年（1705年），彭定求、沈三曾、杨中讷、汪士鋐、汪绎、俞梅、徐树本、车鼎晋、潘从律、查嗣瑮等 10 人奉敕采录，“得诗四万八千九百余首，凡二千二百余人”，共计 900 卷，目录 12 卷。来自[百科](https://baike.baidu.com/item/%E5%85%A8%E5%94%90%E8%AF%97)。

## 数据处理说明

本目录数据经过以下处理：

1. **繁体转简体**：全书 `title` / `author` / `paragraphs` / `notes` / `volume` 统一转为简体（zhconv，`zh-cn`）。
2. **结构化解析**：按唐诗宋词体例整理为 `author` / `paragraphs` / `tags` / `title` / `notes`。作者生平不再逐篇重复，合并进 `authors.json`。
3. **与《全唐诗》去重**：逐篇与 `全唐诗/poet.tang.*.json` 比对。标题去空白、去标点、去乐府类别前缀（相和歌辞、杂曲歌辞等）后比较；正文按字符包含度（containment ≥ 0.90，短文本约等于被长文本完整包含）与 Jaccard 共同判定，容忍异文、脱句，以及部分语料尾部夹带的来源引用/拼音。
   - 重复篇目从本目录移除；
   - 对应《全唐诗》记录追加 `御定全唐诗` 标签。

去重结果（原始 43,103 篇）：

| 类别 | 判定 | 篇数 |
|---|---|---|
| exact | 标题 + 正文完全一致 | 22,965 |
| fuzzy | 同题、正文高度包含（异文/脱句） | 14,837 |
| series | 组诗（题尾「N首」，或题无「N首」而《全唐诗》拆为子篇）按题前缀合并比对 | 1,643 |
| variant | 标题异写、正文高度一致 | 983 |
| **保留（唯一）** | 未在《全唐诗》中找到对应 | **2,675** |

《全唐诗》侧共 **44,556** 条记录追加了 `御定全唐诗` 标签（跨 53 个分片），除 `tags` 外未改动任何字段。

> 卷七百七十（47 篇）已单独补处理：47 篇**全部**与《全唐诗》重复——其中《白纻辞》为杨衡《白纻辞二首》的节录合编（题无「N首」，按同作者题前缀比对，同时命中乐府类与别集类共 4 条记录）。处理后该卷无独有篇目，`770.json`（此时为空数组）已按「删除空文件」一并移除。

## 数据格式

`poet.yuding.<NNNN>.json`，与 `全唐诗/poet.tang.<NNNN>.json` 同构：每片 1000 首，`NNNN` 为该片首条在全集的累计偏移（0 / 1000 / 2000…），4 空格缩进、LF 换行。去重后共 **2,675** 篇，分 3 片（1000 / 1000 / 675）。

卷次信息未丢失：原卷名保存在每篇 `tags` 的第 3 项（如 `卷四`），卷内原序即分片内顺序（先按卷号升序，再按卷内原序）。

```json
[
    {
        "author": "李世民",
        "paragraphs": [
            "秦川雄帝宅，函谷壮皇居。",
            "绮殿千寻起，离宫百雉余。",
            "连甍遥接汉，飞观迥凌虚。",
            "云日隐层阙，风烟出绮疏。"
        ],
        "tags": ["御定全唐诗", "唐", "卷一", "五言"],
        "title": "帝京篇十首 一"
    }
]
```

`tags` 说明：

| tag | 含义 |
|---|---|
| `御定全唐诗` | 集名 |
| `唐` | 朝代 |
| `卷一` … `卷九百` | 原卷名 |
| `五言` / `七言` / `杂言` | 句式；按全篇各句字数是否一致判定，不一致者记为「杂言」 |

`notes` 仅在原卷有注释时出现（已转简体、去空项）。

`authors.json`：作者生平，字段 `name` / `desc` / `id`。原 66 位，补充 79 位，共 145 位。
