## 任务2：热门作者评分功能（author_heat.py 新建 + authors.score 列 + JSON + DB 同步）

### 评分规则（rubric 1.0，docstring 与 JSON meta 均有完整定义）
- 公式：`作者分 = round_half_up((Σscoreᵢ + k·μ)/(n + k))`，1-100；Σscoreᵢ=该作者有效评分诗词 poems.score 之和，n=首数，μ=全局均分（54.18），k=PRIOR_K=20。
- **收缩估计**（关键设计）：53% 作者（6900/13056）只有 1 首有热度分的诗，纯均值下单首名作陌生作者登顶（实测雷震/鲁 98 分压过李白 74）。k=20 后 n=1 作者最高约 56 分（名家区 61-75），n≥100 作者几乎不受影响（苏轼 61.1→61.1）。k=0 退化为纯均值。
- 线性等价：诗词综合分是四维线性函数，mean(20·Σw·d)=20·Σw·mean(d)，故与「先平均四维再综合」等价（仅取整噪声）；权重与诗词一致 breadth .30/span .20/depth .25/now .25。
- 有效评分诗词：poems.score>0 且 author_uid 非空（佚名 3506 首不参与）；≥1 首才入选，0 首的作者 DB score=0（1326 位）。
- 并列名次：标准竞赛排名 1224（同分并列、后续跳号）；并列内按姓名升序→uid 升序，输出确定。
- 结果：13056 位作者上榜；Top：晏几道 77、李白/辛弃疾/向 并列 74、柳永 73、吴文英/蔡伸 72。

## 任务3：分数分档函数 score_band.py（新建，与诗人分级需求相关）
- 规则：0-100 整数分，100-99 为第1档，每两个连续分数一档逐级递减；等价公式 `tier = (100-score)//2 + 1`；第 k 档 = 闭区间 [101-2k, 102-2k]（双端包含，相邻档不重叠无空隙）；共 51 档，**第51档仅含 0 分**（101 个整数两两成档剩一个）。
- 文件：`poetry-pipeline/score_band.py`（score_to_tier / tier_interval / tier_label / iter_tiers + 异常体系 ScoreBandError(ValueError) ← ScoreTypeError(,+TypeError) / ScoreOutOfRangeError）。

- 测试：`poetry-pipeline/test_score_band.py`，22 个用例全过（边界对、区间划分性质、穷举 0-100 roundtrip、单调性、全部异常路径）+ 7 个 doctest。运行：`python -m unittest test_score_band -v`。
